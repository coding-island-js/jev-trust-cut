# 2026-10-02: the cut uses checked rows only

**Decision:** a row counts as evidence only when a person filled its truth column. Unchecked rows are never assumed right or wrong.

**Why:** in the EatList example, 145 disagreements sit between 0.5 and 0.7, and most come from one LA channel whose titles name no place. Guessing their truth would have made the table look complete and the cut look certain. Twelve rows were checked by reading titles that name the place, and the README says so.
